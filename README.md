# DevOps Private Kubernetes Project

A simple DevOps project using:

- GitHub
- GitHub Actions
- Docker
- Docker Hub
- Terraform
- AWS S3
- AWS DynamoDB
- Ansible
- Kubernetes

## Application

A simple Flask application that displays:

- Environment
- Application version
- Health status

## Environments

- QA - 2 replicas
- UAT - 2 replicas
- Production - 3 replicas
